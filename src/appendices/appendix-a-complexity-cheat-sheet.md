# Appendix A: Complexity Cheat Sheet

| Structure | Search | Insert | Delete | Space |
|-----------|--------|--------|--------|-------|
| Array | O(1)/O(n) | O(n) | O(n) | O(n) |
| Linked List | O(n) | O(1)* | O(1)* | O(n) |
| Hash Table | O(1)* | O(1)* | O(1)* | O(n) |
| BST | O(n)/O(log n) | O(n)/O(log n) | O(n)/O(log n) | O(n) |
| AVL/Red-Black | O(log n) | O(log n) | O(log n) | O(n) |
| B-Tree | O(log n) | O(log n) | O(log n) | O(n) |
| Skip List | O(log n)* | O(log n)* | O(log n)* | O(n log n)* |
| Heap | O(n)/O(1) | O(log n) | O(log n) | O(n) |
| Trie | O(L) | O(L) | O(L) | O(AL) |

*Average or amortized
