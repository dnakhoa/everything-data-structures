# Appendix C: Glossary

**ADT (Abstract Data Type)**: A data type defined by its operations, not implementation.

**Amortized**: Average cost over a sequence of operations.

**Balanced Tree**: Tree where heights of subtrees differ by at most a constant factor.

**Collision**: When two keys hash to the same index.

**Cursor**: Position indicator in a data structure.

**Degenerate Tree**: Tree that has degraded to essentially a linked list.

**Fan-out**: Number of children a node can have (B-trees).

**Hash Function**: Function that maps keys to array indices.

**Heap Property**: Parent is greater/less than children (max/min-heap).

**Leaf**: Node with no children.

**Load Factor**: Ratio of elements to capacity (hash tables).

**Persistent**: Preserving previous versions after modification.

**Time Complexity**: How running time grows with input size.

**Space Complexity**: How memory usage grows with input size.
